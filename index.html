PRIVACY NOTICE
LAST UPDATED : 09 OCT 2026 VERSION : 1.1

This Privacy Notice describes how Observation Protocol: The Observed ("the Game") handles data on your device. It applies to both the demo and the full game. Read it in full before you begin observation.

01

Data We Collect

Observation Protocol is a single-player, offline horror game. We do not collect, transmit, or store any personal information about you on external servers.

The Game saves the following data locally on your device only:

  • Game progress — current cycle, completed events, inventory state, room visits
  • Settings preferences — audio, graphics, controls
  • Player journal entries — text you write yourself
02

Steam Platform

If you obtained this Game via Steam, the Steam client may collect data (playtime, achievements, friends list) according to Steam's own Privacy Policy. We do not control or access Steam's data collection.

Refer to Valve's Privacy Policy at store.steampowered.com/privacy_agreement

03

Third-Party Services

Observation Protocol does not use:

  • Analytics services
  • Advertising networks
  • Crash reporting tools (other than Steam's built-in)
  • Cloud saves (other than Steam Cloud, if enabled)
  • Social media integrations
  • External servers of any kind
04

Save File Location

Save files are stored locally at:

C:\Users\<You>\AppData\LocalLow\Vastlyth\Observation Protocol The Observed\

The demo and the full game keep separate save files (each in its own subfolder under Vastlyth). You can delete these files at any time to remove all local game data. This will reset your progress.

05

Audience

Observation Protocol contains psychological horror themes, disturbing imagery, and intense atmosphere. The Game is intended for a mature audience. Parental discretion is advised.

06

Content Warning

The Game features:

  • Psychological horror and disturbing imagery
  • Flickering lights (can be reduced via Settings)
  • Loud sudden sounds (volume adjustable)
  • Themes of isolation and dissociation
  • Brief depictions of fictional surveillance

If any of these may negatively affect your wellbeing, please consider whether this Game is right for you.

07

Accessibility

Settings options to reduce sensory impact:

  • Screen Effects toggle — reduces visual glitches
  • Motion Blur toggle
  • Volume controls per channel — Master, Music, Effects, Ambient
  • Hint System for guidance
  • Subtitle support
08

Changes To This Notice

If we update this Privacy Notice, the new version will be included with future game updates. The date at the top reflects the most recent revision.
